# Resume Screening System

A FastAPI-based backend application that analyzes PDF resumes against job descriptions.

## Features
- PDF Resume Upload
- Skill Extraction
- Experience Detection
- Resume Scoring
- FastAPI REST API

## Tech Stack
- Python
- FastAPI
- Uvicorn
- pdfplumber
- PyPDF2

## Run Locally

pip install -r requirements.txt

uvicorn app.main:app --reload
